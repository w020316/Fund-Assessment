FACTOR RESEARCH / ALPHA 144

先验证因子，再讨论收益。

将历史价量数据变成可复核的证据：复权与过滤、因子排序、IC 检验、分组收益和市值暴露。负相关也可能有信息，漂亮的曲线却不一定是独立 alpha。

01 / 历史数据

仅本项目服务内存计算

上传 UTF-8 CSV 或粘贴内容。最多 20,000 行、200 只股票、1,000 个交易日；日期与股票展开后不超过 100,000 格。

不内置或自动填充模拟行情。
查看字段要求与 Alpha144 公式

date,stock_code,open,close,amount,adj_factor,is_st,listing_days 为必需表头，market_cap 可选。

字段含义
date / stock_codeYYYY-MM-DD / 六位股票代码；同日同股不可重复
open / close未复权开盘价 / 收盘价，单位元
adj_factor该日历史复权因子；价格乘此值，成交额不复权
amount该日真实成交额，单位元；不得用成交量替代
is_st / listing_days该日 ST 状态（0/1）/ 截至该日上市交易日数
market_cap该日总市值，单位元；缺失则不推断小盘暴露

r[t] = adj_close[t] / adj_close[t-1] - 1
Alpha144 = SUM(max(-r, 0) / amount, window) / COUNT(r < 0, window)

窗口必须完整且每天成交额有效；无下跌日时因子不可用。缺失数值留空，不填零；复权价与未复权价不可混用。请包含预热窗口和标签观测期，并提供完整历史股票池、交易日历及当时已知的状态，而非今天的股票列表。

02 / 固定研究规则

当日收盘生成因子，从次日开盘计算远期收益。前段标签若跨入测试段则剔除（purge）；尾部尚未到期的收益不填零。不根据测试段自动选择方向或调参。

点击运行会将 CSV 发送至本项目服务，不持久化、不发送第三方。计算接口沿用管理员鉴权，每分钟最多 3 次。

等待历史数据。上传单只股票无法完成横截面 IC 检验。
