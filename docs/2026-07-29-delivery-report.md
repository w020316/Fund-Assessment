## 1. 项目概览

### 1.1 产品定位

**一句话定位**:基于消息面 + 大盘研判 + 基金重仓分析,为基金投资者提供买卖建议的智能分析平台。

**核心用户**:偏专业的基金投资者,关注基金重仓股和板块轮动,不满足于看净值,要穿透到持仓底层逻辑。

**核心价值主张**:
1. **穿透式分析**:穿透到重仓股、所在板块、大盘趋势,从底层逻辑判断基金走势
2. **消息面驱动**:聚合新闻 + 公告 + 研报 + 舆情,用多智能体辩论提炼出对基金的实际影响
3. **建议而非操作**:给明确的加仓/减仓/持有/观望建议 + 时机判断,但不代用户执行买卖

### 1.2 技术栈

| 层 | 技术选型 | 说明 |
|----|---------|------|
| 前端 | 原生 HTML + Vanilla JS + 原生 CSS | 单文件 SPA,4325 行,深色金融终端风格 |
| 后端 | Python 3.12.11 + FastAPI + Uvicorn | Render Free 实例,512MB RAM |
| 数据源 | akshare + mootdx + 腾讯实时行情 | 6 源降级策略,任一故障自动切换 |
| AI | 智谱 GLM-4-Flash(主) + Agnes agnes-2.0-flash(备) | 双 Provider 故障切换,30s 超时 |
| 缓存 | SQLite + 内存 DataCache | TTL 缓存 + 持久化 |
| 部署 | Render Web Service(Free) | Python 运行时,自动部署 |
| 检索 | Tavily API(可选) | 智能检索增强 |
