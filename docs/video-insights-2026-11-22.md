## 三、映射到本项目的差距（实测，非推测）

线上 version `61372e2`，1440×900 实测五页：

1. **chrome 太厚**：topbar → pill tabs(44px) → 标题+描述(60px) → 面板头，四层；首屏只放得下 2 个面板。
2. **左栏低效**：约 148px，图标+文字竖排，无折叠/无二级菜单；策略页 6 个 pill tab 平铺。
3. **指数条价值低**：3 个纯文字指数，无走势、不可点、不随页变化。
4. **命令面板缺失**：Ctrl+K 仅聚焦搜索框。
5. **面板/空态不统一**：`—`、`上游未返回计数(指数代理)`、整块空白、`未配置 Token` CTA 四种写法并存，空态与错误态不分。
6. **表格不规范**：非等宽数字、无粘性表头、不可排序、单位说明缺失。
7. **工作台不可编排**：写死在 HTML，不能折叠/隐藏/排序/存模板。
8. **数据缺失静默**：板块页 KPI 截图实测出现「上涨 58 个 / 占比 100%」与「下跌 8 个 / 占比 0%」并存——**两个数字不可能来自同一分母，需按口径自洽断言复核**（接口当前返回 50 个全涨，未能复现，列入 QA 断言项）。

## 四、本轮取舍

- **做**：全局骨架（侧栏两态 + flyout、指数条升级）、统一 Panel 三态、命令面板、表格规范、空/错态文案、工作台模板（localStorage）。
- **不做**：引入前端框架、改后端 API 语义、重写存量页面逻辑、自由拖拽（P2）、多智能体辩论（成本高、与"决策辅助"定位弱相关）、日内 CTA（需要分钟级撮合，与现有日频定位冲突）。

## 五、给 QA 的口径自洽断言（新增）

- 板块 KPI：`up + down + flat == pctItems.length`，且 `up%/down%` 必须以同一分母计算；页面同时显示总数与分项时必须可加和。
- 面板三态：同一接口失败时，页面必须出现「错误态」文案（可重试），不得渲染成空数据或 `0`。
- 命令面板：任一页面/标的可在 3 次按键内到达（Ctrl+K → 输入 → Enter）。
