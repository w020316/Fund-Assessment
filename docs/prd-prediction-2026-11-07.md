- **日期**：2026-11-07
- **作者**：许清楚（产品经理）
- **状态**：待主理人拍板
- **项目**：Fund-Assessment（D:/xm/wz/Fund-Assessment）
- **技术基线**：Python 3.12 + FastAPI + 原生 JS 单文件 SPA（web/static/index.html，STAGE5_PAGE_MAP 五容器路由）；已有双上游行情、sector_map.yaml 板块聚合、LLM 三档路由（llm_task_tier.py）、SimulatedBroker、SQLite（trade.db / risk.db，**不改动**）、交易日复盘 Action（gen_daily_report.py + daily-report.yml）

---

## 一、原始需求复述

用户（2026-11-07 晚）：

> 当前项目页面数据内容显示不全，补全；早盘午盘晚盘数据分析、总结；添加股票板块，趋势预测，股票和基金推荐；数据持久化；确保 AI 的准确率在 90 以上，根据每天情况总结，优化 AI 率。

**关键口径（主理人已向用户声明，PRD 全文遵守）**：预测准确率 90% **不可承诺**。替代方案为「预测 → 验证 → 统计 → 优化」闭环，准确率**可测量、可展示、可迭代**。本 PRD 所有 AI 准确率需求均按此口径撰写。

---

## 二、产品目标（3 个，正交）

1. **盘面看得全**：补齐既有页面已知数据缺口（能修的修、上游限制的明示），消除"显示不全"的感知。
2. **盘面看得懂**：新增早盘/午盘/盘后三时段快照与分析总结，以及板块行情、次日趋势预测、股票/基金推荐四个新能力，形成"数据 → 分析 → 结论"链路。
3. **结论可追责**：所有预测与推荐落库持久化，每日自动验证、统计准确率，前端看板 + 周度优化报告驱动 AI 迭代。

---

## 三、用户故事（5 个）

1. As a 个人投资者, I want 每个交易日早/午/盘后三个时点自动生成市场快照与总结, so that 我不用盯盘也能掌握当天节奏。
2. As a 个人投资者, I want 一个独立的股票板块页面（板块涨跌、资金、成分股）, so that 我能快速找到当天强势方向。
3. As a 个人投资者, I want 系统给出次日大盘方向预测与股票/基金推荐（带置信度和理由）, so that 我有可参考的决策输入。
4. As a 个人投资者, I want 看到历史预测被逐日验证的准确率看板, so that 我能判断该系统的结论是否可信，而不是听它自说自话。
5. As a 系统维护者, I want 每周自动生成优化报告指出哪类预测偏差最大, so that 我能据此迭代规则参数与 LLM 提示词。

## 五、关键页面/区块布局要点（非设计稿）

1. **行情容器 → 新增"板块"二级页**：顶部板块涨跌幅排行榜（红涨绿跌，点击展开成分股与资金摘要）；右上角统一新鲜度角标。
2. **监控容器 → "时段分析"区块**（新）：三张时段卡片横排（早盘/午盘/盘后），每张含规则摘要 + LLM 一句话 + 采集时间角标 + "立即采集"按钮；下方"次日预测"卡片（方向、置信度、理由、历史 30 日可展开）；再下方"AI 准确率"卡片（三窗口命中率 + 走势条 + 样本量）。
3. **策略容器 → "今日推荐"区块**（新）：3–5 条推荐列表，每条 = 标的 + 方向 + 置信度标签 + 理由 + 免责声明脚注。
4. **持仓页**：4 只份额近似持仓加"估算值待复核"角标 + 行内编辑。
5. **全局**：所有数据区块统一新鲜度角标规范（更新时间 + 延迟级别），沿用 stage5 设计系统既有 token。

## 六、「不做」清单（防范围蔓延）

1. **不承诺、不展示"准确率 ≥90%"类数字目标**——只做测量与展示。
2. **不接入付费数据源**（Wind/同花顺 iFinD 等）；北向实时数据不自行爬取境外替代源。
3. **不改 trade.db / risk.db 既有表结构**；不动 SimulatedBroker 现有逻辑。
4. **不做真实交易下单**、不做券商 API 对接。
5. **不做用户体系/多账户**；推荐不做个性化（所有人同一份信号推荐）。
6. **不做回测框架升级**（backtest.py 保持现状）；不做 K 线图表库引入。
7. **不做移动端适配**（沿用现有响应式水平）。
8. **不重构 index.html**——新区块在既有 5 容器导航内追加，不做大规模拆分。
