## 一、三条核心旅程

### 场景 A：看行情 → 搜个股 → 读分析

| 步骤 | 记录耗时 | 结果 |
|---|---|---|
| 打开首页 | 2,723ms（含 2.5s 观察窗） | ✅ 骨架屏 → 数据填充，无跳动 |
| 输入代码 510300 | 639ms | ✅ 聚焦光环、输入法正常 |
| 点击搜索并等待 | 3,137ms（含 2.5s 观察窗） | ❌→✅ 首轮"未找到匹配的股票"，修复后返回 `510300 沪深300ETF华泰柏瑞 4.12 -1.69%` |
| 点击结果看详情 | 3,000ms（含观察窗） | ✅ 详情面板打开，但字段多为"—"（见 U6） |

**根因（已用接口与源码双重核实）**
1. 首轮现象：`GET /api/market/search?q=510300` 返回 `data:[]`、`degraded:false`、`quality_score:100`，
   前端只能如实渲染"未找到匹配的股票"。
2. 真因：新浪 suggest 对该查询返回空串后，回退到腾讯 smartbox；腾讯实际格式是
   `sh~510300~沪深300ETF华泰柏瑞~...`（用 `~` 分隔、市场前缀与代码分列、中文名是字面 `\uXXXX`），
   而 `_search_stock_tencent` 只按 `^` 切分 → 全部条目被丢弃 → 返回空列表。
   **数据源明明有数据，却被解析层吃掉了。**
3. 修复（本轮，见 §十）：解析支持 `~` 与 `^` 两种格式、还原 `\uXXXX`、行情查询带市场前缀、
   空结果不再写缓存、数据源全不可达时返回 503 而非伪装成空。
   修复后同一请求返回 1 条结果，价格与涨跌幅正常。

### 场景 B：持仓 → 组合 AI 建议

| 步骤 | 记录耗时 | 结果 |
|---|---|---|
| 切到持仓页 | 1,822ms（含 1.2s 观察窗） | ✅ |
| 生成组合 AI 建议 | 6,622ms（含 6.0s 观察窗） | ⚠️ 权限拦截提示：**即时返回**，非延迟 |

**核实结论**：`loadPortfolioAdvice()` 第一行就检查 `admin_token`，缺失即返回，
所以拦截是**同步、零延迟**的。真正的问题是提示只有一句纯文本：

> "请先在「设置」页配置管理员 Token 后再使用组合建议"

没有按钮、没有链接、没有说明 Token 是什么、去哪申请。
持仓列表区同样只有一句"请先在系统配置页设置管理员 Token 后查看持仓"。

### 场景 C：策略中心 → 扫描

| 步骤 | 记录耗时 | 结果 |
|---|---|---|
| 切到策略页 | 1,828ms（含 1.2s 观察窗） | ✅ |
| 触发扫描 | 3,979ms（含 3.0s 观察窗） | ✅ **正常返回并渲染 5+ 行**（如 920085 N森峰 +120.63%） |

**核实结论**：`runScan('new_high')` 正常渲染结果行；失败时会由 `api()` 弹出持久错误卡，
空数组时渲染"暂无扫描结果"（阶段二 R-13 已修）。**首轮"空表格无语义"结论作废。**
剩余可改进点仅为：扫描结果卡片默认不显示，用户进入策略页看不到"结果区在哪"。

## 八、功能完善度结论

- **已覆盖**：五个主模块、导航切换、骨架屏、空态、错误态、限流提示均可用；
  扫描三态（加载/空/错误）在代码层已完备。
- **真实缺口**：失败与空的语义区分（搜索 API 层）、Token 的可解释性与可操作性。
- **不属于缺陷但影响观感**：首屏引导占位过大、顶栏信息重复、结果卡片默认隐藏。
- **迭代方向**：可信度可视化（数据健康面板）> 配置自助（一键诊断）> 上手引导 > 检索增强。
