# 设计系统增量 · 第二轮阶段 5（2026-10-28）

- 基线文档：`docs/2026-07-29-design-system.md`（色彩/排版/组件主规范）
- 本文只记录阶段 5 新增或变更的规则，未提及部分以基线文档为准
- 证据：`deliverables/gstack/stage5-*`（矩阵 JSON、CWV JSON、探针、截图）

## 1. 触摸目标（变更）

基线为 44×44px；阶段 5 起，`@media (pointer: coarse)` 下以下控件最小 48×48px：

| 选择器 | 场景 |
| --- | --- |
| `.btn` / `.st6-group-manage .btn` | 主按钮、分组管理面板按钮 |
| `.tab` / `.hud-subtab` / `.st6-window-tab` | 页内与二级 Tab |
| `.bottom-tab-item` / `.nav-item` | 底部导航、侧栏导航 |
| `.st6-group-chip` / `.st6-group-head` | 持仓分组筛选 chip、分组头 |
| `.st6-group-manage-btn` / `.modal-close` | 分组管理入口、弹窗关闭 |

- 桌面细指针保持 44px 设计系统基线。
- 豁免：正文内行内文字链接（如持仓口径说明中的「基金管理」跳转），
  适用 WCAG 2.5.8 inline 例外；矩阵中 375px 仅剩此 1 处 44–47px 项。

## 2. 字号（变更）

- 新增全站可读下限 **10px**：底部 Tab 标签在 ≤768px 与 ≤360px 两档由 9px/8px 提升为 10px。
- 现有字号分布（阶段 5 审计）：10/11/12/13 为正文与标签，14/15/18 为小标题，
  22/24/26/32 为数据展示；11px 以下仅 10px 一档（系统时间、局部角标、描述行）。
- 后续收敛目标（未实施）：把 11–13px 收敛为 3 档 type token。

## 3. 圆角与间距（盘点，未改视觉）

- 圆角 token：`--radius: 8px`、`--radius-lg: 12px`；现状另有 3/4/5/6/10px 硬编码。
  约定：3–4px 用于角标/标签，6px 用于 chip，8px 用于卡片与输入，10–12px 用于弹层。
- 间距：沿用 4px 网格（4/6/8/10/12/16/20/24）；新增块均按该网格取值。

## 4. 反馈文案（新增）

`api()` 错误统一中文呈现，且保留原始错误到 console 便于诊断：

| 情形 | 用户文案 |
| --- | --- |
| 请求超时 | `请求超时(Ns)` |
| 网络不可达（Failed to fetch / Load failed / NetworkError） | `网络连接失败` |
| 其他 | 服务端返回的中文消息或 `网络异常` |

## 5. 空态 / 错态（新增）

指数条与指数卡片区分三态，不再用「加载中」掩盖失败：

| 状态 | 指数条 | 卡片区 |
| --- | --- | --- |
| 加载中 | `指数加载中…`（首屏占位） | — |
| 获取失败 | `指数数据暂不可用` | 标题「指数数据获取失败」+ 建议「请稍后刷新或检查数据源」 |
| 空数据 | `指数暂无数据` | 标题「指数数据暂无」+ 说明「数据源暂未返回行情」 |

## 6. 指数带渐隐（新增）

- 横向可滚动时右侧 20px `mask-image` 渐隐，作为滚动暗示；滚动条保持隐藏。
- **仅 `≤1200px` 启用**：mask 会强制合成层，宽屏不溢出时实测多付约 60ms LCP
  （A/B：514ms vs 454ms），故不用于 1440/1920。

## 7. 口径提示（新增组件 `.notice-info`）

- 用途：区分「模拟股票账户」与「真实基金持仓」，附站内跳转。
- 样式：`padding: 10px 12px`、`font-size: 12px`、`line-height: 1.6`、
  青色 `rgba(6,182,212,.08)` 底 + `.25` 边框、`--radius` 圆角。

## 8. 动效（变更）

- 过渡统一 0.2s（按钮类），不改既有动画编排。
- 新增 `@media (prefers-reduced-motion: reduce)` 全站兜底：动画/过渡时长 0.01ms、
  迭代 1 次、`scroll-behavior: auto`。

## 9. 静态资源缓存（新增平台规则）

- `/static/*.html`：`Cache-Control: public, max-age=60, must-revalidate`
- `/static/*`（其余）：`Cache-Control: public, max-age=300`
- 业务 `/api/*` 不加缓存头；ETag/Last-Modified 继续生效（过期后 304 复用）。

## 10. 响应式头部（新增）

- 基金页头部 `≤768px` 两段式：标题独占一行，操作区单行横向滚动（隐藏滚动条）；
  375px 实测头部高度 96→80px，无重复 CTA。
