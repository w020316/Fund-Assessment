### 2.1 R-02/R-06 专项结论（明确）

- **结论：未达标。净值缺失时仍显示 `0.0000` / `0.00%`，未显示"数据缺失"。**
- 后端本身把缺失值"制造"成 0：[fund.py](file:///d:/xm/wz/Fund-Assessment/web/routes/fund.py#L211-L216)
  ```python
  current_nav = _safe_float(quote.get("nav", 0))
  pnl_pct = (...) if cost_nav > 0 and current_nav > 0 else 0.0
  pnl_amount = (...) if current_nav > 0 and cost_nav > 0 else 0.0
  market_value = current_nav * shares if current_nav > 0 else 0.0
  ```
  缺失 → `current_nav=0.0`、`pnl_pct=0.0`、`pnl_amount=0.0`，前端无法区分"真 0"与"缺失"。
- 前端直接照渲染：[index.html](file:///d:/xm/wz/Fund-Assessment/web/static/index.html#L4386-L4396)（`(p.current_nav || 0).toFixed(4)`、`(p.pnl_pct >= 0 ? '+' : '') + …`）与 [index.html](file:///d:/xm/wz/Fund-Assessment/web/static/index.html#L4342) 卡片同源。
- 唯一的"缺失"提示只有新鲜度徽章"估算 · 净值日期缺失或无法解析"，属于日期维度，不覆盖净值/盈亏数值。
- **修复方向（未实施）**：后端对缺失净值返回 `null`（而非 0.0）；前端用统一 `fmtMaybe()` 渲染"—/数据缺失"，并对 `null` 不做正负号判断。验收：写入无行情代码后，页面不得出现 `0.0000`、`+0.00%`。

## 6. Nielsen 10 条启发式走查

1. **系统状态可见性**：首屏与加载骨架尚可，但 25.7s 分析、45s 回测无进度；降级 4ms 返回 200 让人误以为有结果 → 部分命中。
2. **系统与真实世界匹配**：出现"管理员 Token / Provider / `[降级] 404…` / `/api/fund/positions`"等内部语言 → 未命中。
3. **用户控制与自由**：删除有二次确认，可返回；但补录向导"保存并下一步"无法撤销、且已写库 → 未命中。
4. **一致性与标准**：红涨绿跌、按钮、空态风格一致；但"编辑"按钮无行归属、风险/归因两组同名 tab → 部分命中。
5. **错误预防**：基金代码/份额/成本前端即时校验（K7）有效；但允许把无行情代码当持仓、向导编辑即落库 → 部分命中。
6. **识别优于回忆**：主要入口有文字标签；但窗口 tab 的作用域需记忆，空态方位错误 → 部分命中。
7. **灵活与高效**：缓存命中让重复分析 15–41ms；无键盘快捷、无批量操作 → 部分命中。
8. **美学与极简**：信息密度偏高（20 个二级页、4 个一级导航、三类窗口 tab），首屏尚清爽 → 部分命中。
9. **错误恢复**：toast 有中文口径，但只保留 3s、无重试、无错误面板 → 未命中。
10. **帮助与文档**：三问页有解释性文案与本工具免责声明；缺首次使用引导/Token 获取指引 → 部分命中。
