## 1. 快速开始

### 1.1 系统要求

- 现代浏览器: Chrome 90+ / Firefox 88+ / Edge 90+ / Safari 14+
- 屏幕分辨率: 桌面端 1280px+ / 平板 768px+ / 移动端 360px+
- 网络: 需要稳定的互联网连接

### 1.2 首次访问

1. 打开浏览器,访问 https://fund-assessment.onrender.com
2. 系统会自动加载行情总览页
3. 顶部状态栏显示: 系统时间、数据质量徽章、数据新鲜度、LLM Provider 状态
4. 左侧导航栏(桌面端)或底部 Tab(移动端)切换页面

### 1.3 顶部状态栏说明

| 图标 | 含义 |
|------|------|
| 绿色徽章 "实时" | 数据源正常,数据实时 |
| 黄色徽章 "延迟" | 数据源降级,数据有延迟 |
| 红色徽章 "模拟" | 数据源全部不可用 |
| 闪烁绿点 | 数据新鲜(1 分钟内) |
| 黄点(不闪) | 数据陈旧(超过 5 分钟) |

## 2. 核心功能操作指南

### 2.1 行情总览(首页)

**功能**: 大盘指数+板块轮动+涨跌榜+全球指数 Ticker

**操作**:
1. 进入首页后自动加载上证/深证/创业板指数
2. 顶部指数栏横向滚动显示全球指数
3. 点击"涨幅/跌幅/成交额"切换热门股票榜单
4. 查看板块排行(含主力净流入)
5. 页面每 5 秒自动刷新指数与热门股票

**快捷键**: 无

---

### 2.2 智能分析(核心场景 1)

**功能**: 多智能体辩论分析个股

**操作**:
1. 点击左侧导航"智能分析"
2. 在输入框输入 6 位股票代码(如 `600519`)
3. 点击"深度分析"按钮(等待 20-60 秒)
4. 查看结果:
   - 4 个分析师卡片(基本面/技术/情绪/新闻): 信号+置信度+评分+观点
   - 多空辩论面板: 多头 vs 空头论点+得分
   - 最终决策: 买入/卖出/持有 + 置信度

**注意事项**:
- 按钮点击后会显示"处理中..."并禁用,防止重复提交
- 等待期间请勿关闭页面
- 如超时(15s),会显示"分析超时"提示,可点击重试

---

### 2.3 基金建议(核心场景 2,P1 新功能)

**功能**: 五信号融合建议+基金多智能体分析

**操作步骤**:

#### 步骤 1: 添加基金持仓
1. 点击左侧导航"我的基金"
2. 在"添加基金"卡片中:
   - 输入基金代码或名称搜索(如 `110022` 或 `白酒`)
   - 从下拉列表选择基金(自动填充代码+名称)
   - 填写份额、成本净值、买入日期
   - 点击"添加持仓"按钮

#### 步骤 2: 查看持仓概览
- 顶部 4 个统计卡片: 持仓市值/总成本/累计盈亏/持仓数量
- 持仓列表显示: 代码/名称/份额/成本/现净值/涨跌幅/盈亏

#### 步骤 3: 查看大盘温度计
- 点击"大盘温度"按钮
- 显示 0-100 温度计评分+趋势判断+4 维度信号

#### 步骤 4: 查看消息面聚合
- 点击"消息面"按钮
- 显示热点事件+情绪指数+利好/利空/中性统计
- 在检索框输入关键词(如"白酒板块"),点击"检索"
- 等待 10-20 秒,显示 AI 总结+相关消息列表

#### 步骤 5: 五信号融合建议
- 点击"五信号建议"按钮
- 显示每只持仓基金的五信号评分+建议动作+置信度+关键理由+风险点

#### 步骤 6: 基金多智能体深度分析(核心)
- 在持仓列表行点击"深度"按钮
- 弹出模态框,显示"7 位分析师正在会诊,预计 20-60 秒"
- 等待完成后显示:
  - **投资决策卡片**: 动作(买入/卖出/持有)+置信度+目标价+止损位+仓位建议
  - **7 位分析师观点**: 角色+立场+评分+观点
  - **多空辩论**: 多头论点 vs 空头论点
  - **风险辩论**: 风险点清单

#### 步骤 7: 查看重仓股
- 在持仓列表行点击"分析"按钮
- 弹出模态框显示前 10 大重仓股(代码/名称/权重/板块/涨跌幅)
- 显示板块分布+集中度+预估净值影响

#### 步骤 8: 删除基金
- 点击持仓列表行的"删除"按钮
- 弹出确认对话框(支持 ESC 取消)
- 点击"确认"删除

## 3. 常见问题解答(FAQ)

### Q1: 页面加载缓慢怎么办?

**A**: 
- 检查网络连接
- 查看顶部数据质量徽章,如果是"模拟"则数据源全部不可用
- 刷新页面重试
- AI 分析类操作需要 20-60 秒,属正常现象

### Q2: AI 分析超时怎么办?

**A**:
- AI 分析依赖免费 LLM 模型,服务繁忙时可能超时
- 点击"重试分析"按钮重新尝试
- 避开高峰时段(9:30-15:00)使用
- 简化输入(如使用快速分析而非深度分析)

### Q3: 数据显示"加载中..."不消失?

**A**:
- 数据源可能全部降级,检查顶部徽章
- 等待 15 秒后刷新页面
- 如果持续显示,联系管理员

### Q4: 添加基金持仓失败?

**A**:
- 检查基金代码是否正确(6 位数字)
- 确保份额大于 0
- 检查网络连接
- 查看错误提示 toast

### Q5: 如何获取管理员 Token?

**A**:
- 管理员 Token 通过环境变量 `ADMIN_TOKEN` 配置
- 仅管理员可执行写操作(交易/持仓/配置)
- 普通用户无需 Token 即可查看所有数据

### Q6: 移动端体验如何?

**A**:
- 移动端(768px 以下)自动隐藏侧边栏,显示底部 Tab
- 底部 Tab 包含 10 个核心功能入口
- 360px 以下 Tab 标签自动缩小

### Q7: 数据多久更新一次?

**A**:
- 指数/热门股票: 5 秒自动刷新
- 基金净值: 15 秒缓存
- 板块数据: 60 秒缓存
- AI 分析结果: 不缓存(每次重新分析)
- 新闻数据: 300 秒缓存

### Q8: 支持哪些浏览器?

**A**: 
- Chrome 90+(推荐)
- Firefox 88+
- Edge 90+
- Safari 14+
- 不支持 IE

### Q9: 如何删除基金持仓?

**A**:
- 在"我的基金"页的持仓列表中,点击对应行的"删除"按钮
- 弹出确认对话框
- 点击"确认"或按 ESC 取消

### Q10: 数据源故障时怎么办?

**A**:
- 系统会自动降级到备用数据源(6 源 3 级降级)
- 顶部徽章会显示当前数据质量(实时/延迟/模拟)
- "模拟"徽章表示所有数据源不可用,显示的是占位数据

## 5. 数据准确性说明

### 5.1 数据源

| 数据类型 | 主源 | 备用源 |
|---------|------|--------|
| A 股行情 | 腾讯 | 东方财富 |
| K 线 | mootdx | 东方财富 → 新浪 |
| 板块数据 | 东方财富 | 新浪 → 腾讯 |
| 基金净值 | 腾讯 | - |
| 美股/港股 | 东方财富 | - |

### 5.2 数据延迟

- 实时行情: 延迟 < 3 秒
- 基金净值: 延迟 1-15 分钟
- 板块数据: 延迟 1-5 分钟
- 新闻: 延迟 5-30 分钟

### 5.3 AI 分析准确性

- AI 分析基于大语言模型,仅供参考,不构成投资建议
- 分析结果受 LLM 模型能力限制
- 五信号融合权重: 消息面 25% / 技术面 20% / 基本面 20% / 重仓股 20% / 大盘 15%
- 建议结合个人判断使用

## 6. 故障排查

### 6.1 页面白屏

1. 检查浏览器控制台(F12)是否有错误
2. 清除浏览器缓存
3. 尝试无痕模式
4. 检查浏览器版本是否支持

### 6.2 API 请求失败

1. 检查网络连接
2. 查看服务是否在线(访问 `/api/health`)
3. 检查请求参数是否正确
4. 联系管理员查看服务日志

### 6.3 AI 分析失败

1. 查看 `/api/health/llm` 检查 LLM Provider 状态
2. 如果所有 Provider 不可用,等待恢复
3. 如果单个 Provider 不可用,系统会自动切换
