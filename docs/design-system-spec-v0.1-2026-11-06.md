## 1. 设计理念：深空指挥舱

QuantFlow Pro 是**决策辅助工具**，不是娱乐化产品。未来科技感的边界必须是"**冷静的精密仪器**"，而不是"赛博朋克主题乐园"。

**三层视觉结构**（一切视觉元素必须能归入其中一层，否则不允许存在）：

| 层 | 职责 | 元素 | 视觉权重 |
|---|---|---|---|
| **底座层** | 空间感与深度 | 深空底色、极细网格、静态渐变光晕 | 最低（≤8% 不透明度） |
| **信息层** | 承载全部可读内容 | 实底面板、玻璃面板、1px 发丝描边 | 中（内容对比度 ≥4.5:1） |
| **信号层** | 只表达状态与焦点 | 霓虹描边、焦点环、状态点、进度指示 | 最高，但**面积最小**（≤5% 可视面积） |

**三条铁律**

1. **光只描边，不填内容** — 霓虹用于边、环、点、线的描边与投影，绝不填充大块内容区。
2. **霓虹只标状态，色不承语义** — 涨跌/告警/错误一律使用 `--qf-sem-*`，霓虹色不可替代语义色。
3. **动效只做反馈，不做表演** — 交互动效时长 200–500ms；任何装饰动效不得与交互动效作用于同一元素。

## 3. 字体系统

### 3.1 字体族

| 角色 | 字体栈 | 理由 |
|---|---|---|
| `--qf-font-display` 科技展示字 | `'Chakra Petch','Bahnschrift','DIN Alternate','Rajdhani',sans-serif` | 半方形几何骨架 + 小写高 x-height，具"仪表读数"气质；`Bahnschrift` 为 Windows 内置，离线可用 |
| `--qf-font-body` 正文 | `'HarmonyOS Sans SC','PingFang SC','Source Han Sans SC','Noto Sans SC','Microsoft YaHei UI','Microsoft YaHei',sans-serif` | 中文正文必须用高质量黑体；**禁止用展示字排中文** |
| `--qf-font-mono` 数据/代码 | `'JetBrains Mono','Cascadia Mono','SF Mono','Consolas',monospace` | 等宽数字，用于代码、ID、行情数值 |

> **"专属科技感字体"的落地定义**：展示字只承担**拉丁字母与阿拉伯数字**（标题、KPI 大数），中文一律走 body 栈。这是为了保证中文 400/500/700 三档字重真实可用——展示字没有中文字形，强行用会触发浏览器合成粗体，出现糊字。此为本设计系统的**字体使用红线**。

**数字统一规则**：所有数值（价格、涨跌幅、金额、比率）必须 `font-variant-numeric: tabular-nums slashed-zero;`，保证列对齐、`0` 与 `O` 不混淆。

### 3.2 字阶（11 级）

| Token | 字号/行高 | 字重 | 字间距 | 字体族 | 使用场景 |
|---|---|---|---|---|---|
| `--qf-display-1` | 56 / 64 | 700 | `-0.02em` | display | 仅品牌 Hero（桌面）；移动降为 34/40 |
| `--qf-display-2` | 40 / 48 | 700 | `-0.01em` | display | 页面主标题（桌面）；移动 28/36 |
| `--qf-h1` | 32 / 40 | 700 | `-0.01em` | display + 中文 body | 模块标题；移动 26/34 |
| `--qf-h2` | 24 / 32 | 600 | `0` | body | 卡片组标题 |
| `--qf-h3` | 20 / 28 | 600 | `0` | body | 卡片标题 |
| `--qf-h4` | 18 / 26 | 600 | `0` | body | 小节标题、表头组 |
| `--qf-body-l` | 16 / 24 | 400 | `0` | body | 长文正文；移动 16/26 |
| `--qf-body` | 14 / 22 | 400 | `0` | body | 默认正文；移动 15/24 |
| `--qf-body-s` | 13 / 20 | 400 | `0.01em` | body | 表格、紧凑列表；移动 13/22 |
| `--qf-caption` | 12 / 16 | 500 | `0.04em` | body | 时间戳、单位、辅助说明 |
| `--qf-micro` | 11 / 16 | 600 | `0.08em` | display（大写）+ body（中文） | 分类标签、坐标轴、角标 |
| `--qf-data-xl` | 32 / 36 | 700 | `-0.01em` | display tabular | KPI 主数值 |
| `--qf-data` | 14 / 20 | 600 | `0.02em` | body tabular / mono | 表格数值 |
| `--qf-code` | 12 / 18 | 500 | `0.02em` | mono | 代码、股票代码、ID |

**硬性规则**
- 行高最小 1.4（`--qf-body` = 22/14 ≈ 1.57），杜绝 1.2 以下的"贴行"。
- 字重只用 400 / 500 / 600 / 700 四档，禁止 300（暗底细字会糊）。
- **渐变文字只允许 ≥24px 且字重 ≥700**（低于该阈值对比度不可控），且必须叠加 `text-shadow: 0 0 18px rgba(34,227,255,.25)` 保证暗底上的边缘清晰。
- 单行文本截断必须用省略号并提供 `title`；表格数值列**禁止截断**，改为横向滚动。

## 4. 间距系统（8px 栅格）

| Token | 值 | 用途 |
|---|---|---|
| `--qf-space-0` | 0 | — |
| `--qf-space-0_5` | 4px | **仅限**：图标与文字间距、描边偏移、徽章内竖向内边距 |
| `--qf-space-1` | 8px | 最小间距单位、控件内 gap |
| `--qf-space-2` | 16px | 卡片内元素间距、表单行距 |
| `--qf-space-3` | 24px | 卡片内边距（桌面）、栅格 gutter |
| `--qf-space-4` | 32px | 区块间距、页面左右边距（桌面） |
| `--qf-space-5` | 40px | 大区块分隔 |
| `--qf-space-6` | 48px | 页面级分段 |

## 7. 动效系统

### 7.1 时长（令牌化，范围硬约束 200–500ms）

| Token | 值 | 适用 |
|---|---|---|
| `--qf-dur-1` | 200ms | hover、press、focus、描边变化（**最短，不可再短**） |
| `--qf-dur-2` | 240ms | 开关、徽章、chip、勾选 |
| `--qf-dur-3` | 320ms | 卡片展开、标签页切换、抽屉露出 |
| `--qf-dur-4` | 420ms | 页面/路由转场、模态出现 |
| `--qf-dur-5` | 500ms | 上限：全屏转场、复杂编排（**禁止超 500ms**） |

**例外声明（必须写入开发约定）**：*环境循环动效*（光晕呼吸 6s、骨架微光 1.4s、流动光 8s）不属于"交互动效"，不受 200–500ms 约束，但必须满足：① 仅 `transform`/`opacity`；② 不覆盖可读文本；③ `prefers-reduced-motion: reduce` 时全部关闭。

### 7.2 缓动曲线

| Token | 曲线 | 用途 |
|---|---|---|
| `--qf-ease-standard` | `cubic-bezier(.2,.8,.2,1)` | 默认（hover/press） |
| `--qf-ease-enter` | `cubic-bezier(.16,1,.3,1)` | 元素进入（减速，柔和收尾） |
| `--qf-ease-exit` | `cubic-bezier(.4,0,1,1)` | 元素离开（加速，干脆） |
| `--qf-ease-emphasis` | `cubic-bezier(.34,1.4,.64,1)` | 仅用于 ≤24px 的小元素回弹（scale ≤1.04） |

**禁止**：`linear` 用于任何交互动效；`ease-in-out` 用于进入动画；超过 1.08 的缩放回弹（会导致 60fps 下的二次抖动）。

|---|---|---|---|---|---|

## 8. 元素使用场景与禁用规则

### 8.1 霓虹渐变

- ✅ **允许**：品牌 Logo 区、Hero 主视觉（单屏 1 处）、主 CTA 按钮填充、进度/选中指示条、图表单一高亮系列。
- ❌ **禁止**：正文文本背景；表格单元格；大面积容器底（>320×180 或 >15% 可视面积）；与玻璃层叠加后仍可见（必须先落实底）；同屏出现 2 个以上大面积渐变。
- 渐变上的文字：亮度 ≥0.45 的端点（cyan / magenta / 涨跌色）上必须用 `--qf-ink`，**禁止白字**（实测白字在 `#22E3FF` 上仅 1.65:1）。

### 8.2 赛博朋克元素（扫描线 / 网格 / 角标 / 故障字 / 铬字）

- ✅ **允许**：品牌头图、页面转场瞬间（≤500ms）、加载态、空态插画、分节装饰线。
- ❌ **禁止**：任何数据表格、图表绘图区、表单标签、正文 3 行以上的文本区、数值单元格周边 120px 内。
- 扫描线不透明度 ≤0.06，网格线 ≤0.035；**故障（glitch）效果禁止作用于任何可读文字**（含标题）。

### 8.3 玻璃拟态

- ✅ **允许**：顶栏、浮层、导航、Hero 信息卡；**最多 2 层嵌套**。
- ❌ **禁止**：作为长文阅读区底色（会与背后内容打架降低可读性）；叠在流动光斑/动效层上（必须加不透明遮罩）；`backdrop-filter` >16px（渲染成本高，中低端机掉帧）。
- 强制配套：`1px` 发丝描边 + 顶部内高光 + 不透明度 ≥0.55（不足时降级为实底 `--qf-bg-surface`）。

### 8.4 动态流动光效

- ✅ **允许**：Hero 背景、空态、加载页、品牌转场。
- ❌ **禁止**：表格/图表/表单内；文字块背后**无遮罩**的位置；同屏 >1 处。
- 强制：仅 `transform`/`opacity`；周期 ≥6s；`prefers-reduced-motion` 与页面 `visibilitychange` 隐藏时必须暂停。

### 8.5 科技展示字

- ✅ **允许**：拉丁字母标题、KPI 大数、全大写 `micro` 标签。
- ❌ **禁止**：中文正文（无中文字形，会触发合成粗体）；表格数字列（改用 tabular body/mono）；按钮内的中文文案（用 body 栈 500）。

### 8.6 十条硬性禁用组合

| # | 禁用组合 | 原因 |
|---|---|---|
| 1 | 霓虹大面积渐变 **+** 玻璃层 | 玻璃会把渐变打散成噪点，文字对比不可控 |
| 2 | 流动光斑 **+** 正文文字（无遮罩） | 亮斑扫过时文字瞬时对比度跌破 3:1 |
| 3 | 扫描线 **+** 数据表格/图表 | 干扰数值读取，违反"光不填内容" |
| 4 | 霓虹色 **+** 涨跌/告警语义 | 语义色必须唯一，混用会造成误判 |
| 5 | 同屏 **2 个以上**大面积渐变 | 视觉失去焦点，信号层面积超预算 |
| 6 | 玻璃层嵌套 **>2 层** | 叠加后对比度不可预测，性能骤降 |
| 7 | glitch/shake **+** 可读正文或数值 | 直接影响信息识别 |
| 8 | 装饰动效 **+** 交互动效（同一元素） | 操作反馈被淹没，违反"动效优先级低于操作响应" |
| 9 | 展示字 **+** 中文正文/表格数字 | 字重与等宽失真 |
| 10 | 仅靠颜色 **+** 区分状态（无图标/文字/形状） | 色盲与强光环境失效，违反 WCAG 1.4.1 |

## 10. 落地映射与工程约定

### 10.1 与存量 token 的映射（零组件改写）

| 设计系统 token | 存量 token | 说明 |
|---|---|---|
| `--qf-bg-void` | `--bg-primary` | 页面底 |
| `--qf-bg-surface` | `--bg-card` | 卡片 |
| `--qf-bg-elev2` | `--bg-card-hover` | 卡片 hover |
| `--qf-line-1` / `--qf-line-2` | `--border` / `--border-light` | 描边 |
| `--qf-text-primary` / `-secondary` / `-muted` | `--text-primary` / `-secondary` / `-muted` | 文本 |
| `--qf-neon-cyan` | `--accent` / `--hud-accent` | 主强调 |
| `--qf-sem-up` / `--qf-sem-down` | `--color-up` / `--color-down` | 涨跌（保持 A 股语义） |
| `--qf-sem-warn` | `--color-warning` | 警告 |

> 沿用现有 `body.hud-theme` 作用域铁律：新增 token 只在该作用域下生效，移除类即整体回退。设计系统不侵入存量内联样式。

### 10.2 工程约定

1. **所有视觉值必须走 token**，禁止在组件里写裸色值/裸尺寸（lint 阶段可加规则拦截 `#` 与非 8 倍数 px）。
2. **动效只允许 `transform` / `opacity` / `box-shadow`**，禁止 `width/height/top/left` 过渡（会触发重排，跌落 60fps）。
3. **`backdrop-filter` 预算**：单页同时存在 ≤3 处，blur ≤16px。
4. **`@media (prefers-reduced-motion: reduce)` 必须关闭全部动画与过渡**（与存量 hud.css 已有实现保持一致）。
5. **断点**：移动 `<768`、平板 `768–1200`、桌面 `>1200`；用 `min-width` 优先（平板用 `768 ≤ x ≤ 1200` 显式区间，避免 1200 边界抖动）。

## 12. 需你确认的 5 个风格决策

1. **设计方向**：`Aurora Terminal`（冷青极光 + 克制赛博，信息优先）。是否接受？或希望更"暗黑机甲"（更多角标/切角）／更"极简专业"（去掉扫描线与网格）？
2. **主强调色**：`#22E3FF` 冷青。是否保留？备选 `#5AC8FA`（更柔和，更接近传统金融终端）。
3. **品牌渐变**：`青 → 蓝 → 紫 → 品红` 四段。若嫌紫红过重，可收为三段 `青 → 蓝 → 紫`。
4. **科技展示字体**：`Chakra Petch`（几何骨架、仪表盘气质）。备选 `Rajdhani`（更窄更高，更"军工"）。
5. **玻璃强度**：`blur 16px + 0.62 不透明度`。是否希望更透（更强纵深感）或更实（更强可读性）？

> 确认后进入 S2：把这套 token 落成真实组件库（按钮/输入/导航/卡片/表格/弹窗/空错载态全部状态机），并绑定到现有页面结构，产出全业务场景可交互原型。
