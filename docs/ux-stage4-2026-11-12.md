## 改进建议（≥5 条）

1. **因子实验室内置一键样例数据**（把走查用受控 CSV 缩样随包分发），预期：新用户 0 门槛跑通全流程；难度低；P1。
2. **热力图加色标图例**（渐变条 + 两端标注 IR 区间），预期：判读零学习成本；难度低；P2。
3. **自定义行内校验提示**（pattern 不满足时在字段下方显示红字），预期：移动端/触屏可感知；难度低；P2。
4. **首页瘦身立项**（471KB/8652 行单文件拆分是历轮 backlog，本轮维持），预期：networkidle 显著下降；难度高；P3。
5. **MA 网格结果导出 CSV**（与因子报告 JSON 导出对齐），预期：研究留档；难度低；P3。

## 新功能建议（roadmap，≥3 条）

1. **网格高原识别**：不止标最优格，用滑窗均值把"成片高原"着色——直接回应页面自己的劝告文案；用户价值高/难度中/P1。
2. **多标的热力图对比**：一次跑 3-5 只持仓股票的网格，横向比较参数稳定性；价值中/难度中/P2。
3. **因子检验结果一键生成研究小结**（接 light 档 LLM，呼应"light 档零流量"backlog）：价值中/难度低/P2。
