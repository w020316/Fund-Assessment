## 1. 背景与目标

### 1.1 输入来源

用户提供 14 条抖音视频，其中**唯一明确动作指令**是：「参考一下这个 UI 给我的所有页面完善一下」。其余 13 条按其主题归为 5 组，仅作为「本轮不做功能扩张」的判断依据：

| 组 | 主题 | 对本 PRD 的作用 |
|---|---|---|
| 1 | 数据源/自部署（4 条：同花顺 API 开源、自部署股票数据服务、散户数据来源盘点、量化数据"三道防线"） | 数据可信度必须有可视化出口 → 落到 P0「数据降级/缺失必须解释」 |
| 2 | 选股/因子（2 条：AI 选股平台、散户量化定位） | 能力已有（信号扫描/因子研究），本轮只做入口聚合 |
| 3 | 结构分析/资金（2 条：缠论开源指标、主力资金看板） | 能力已有，需要「模块化上屏」而非新增算法 |
| 4 | AI 多智能体交易（1 条） | 已有智能分析/一句话调度，本轮不扩 |
| 5 | 投研/持仓视角（2 条：国家队持仓、日内 CTA、什么是量化） | 已有机构持仓/持仓管理，只改组织方式 |

参考 UI（糖葫芦看盘软件）的 4 个可借鉴点：**横向指数情绪条**、**图标竖排左导航 + hover 二级悬浮菜单**、**可拼装模块栅格 + 模板保存**、**全局搜索直达**。

### 1.3 本轮目标（3 个正交目标）

1. **降 chrome、提密度**：1440×900 首屏可见面板数从 2 → ≥3，chrome 高度（视口顶 → 首个面板内容上沿）下降 ≥30%。
2. **重建导航骨架**：左栏两态折叠（56/168）+ hover flyout 承载二级页；顶部一条指数情绪条；`Ctrl+K` 命令面板 3 次按键内可达任一页面/标的。
3. **统一语言**：所有面板/表格/空错态/徽标/按钮位置收敛到一套可被 QA 断言的规范（`data-*` 钩子）。

### 1.4 边界（硬约束）

> **不改后端能力，只重排前端信息架构与交互。**

- 不改任何 HTTP API 的路径、参数、返回结构、语义；不新增后端端点。
- 不引入前端框架/构建链（继续原生 HTML/CSS/JS，直接改 `web/static/`）。
- 不重写存量页面业务逻辑（`switchPage`、各 `*.js` 的 load/render 函数保持契约）。
- 不动 `STAGE5_PAGE_MAP`（`index.html:3723` 起的唯一权威映射），旧页兼容路径必须零死链。
- 不删除任何已有面板/数据卡片（只做重排、折叠、隐藏开关）。
- 不动 `tokens.css` 的既有 token 值；新增 token 只允许追加。

## 3. 用户故事（含验收要点）

> 格式：As a …, I want …, so that …。验收要点均可用 Playwright/DevTools 断言。

**US-1（骨架 / S1）** 作为盘中用户，我希望顶栏与页面之间只有一层上下文条，这样我打开就在看数据而不是在看导航。
- 验收：1440×900 下 `chromeHeight ≤ 136px`（测量方式见 §6-M2）；`.topbar` 计算高度 `=== 48px`；`.qf-ctxbar` 计算高度 `=== 36px`；页面内不存在重复的 `.qf-page-title` 大标题（`document.querySelectorAll('.page.active .qf-page-title').length === 0`）。

**US-2（侧栏 / S2）** 作为高频切页用户，我希望左栏能一键收成 56px 图标轨、hover 就展开二级菜单，这样我不必回到顶部去找 pill。
- 验收：`.sidebar` 宽度在 56 ↔ 168 之间切换且状态持久化到 `localStorage['qf.sidebar.expanded']`；hover ≥150ms 出现 `.qf-flyout`（宽 220px，含当前一级页全部二级项，项数 === `STAGE5_PAGE_MAP` 中该 parent 的子项数）；键盘 `Tab` 也能打开 flyout（`aria-expanded="true"`）。

**US-3（指数条 / S1）** 作为判读用户，我希望顶部一条就能看到指数 + 温度 + 情绪 + 涨停，并且能点进去，这样我不用先去行情页。
- 验收：`.qf-index-bar` 内条目数 ≥4，每条含 `canvas/svg` 迷你走势（宽 ≥40px、高 ≥16px）、名称、现价、涨跌幅；点击任一条目后 `location` 不变但 `document.querySelector('.page.active').id` 切到行情上下文且该指数对应卡片 `data-index-code` 高亮；数据缺失时条目显示 `—` 且 `title` 含缺失原因（非空字符串）。

**US-4（命令面板 / S2）** 作为键盘用户，我希望 `Ctrl+K` 能搜页面、基金、股票、板块并回车直达，这样我 3 次按键就能到任何地方。
- 验收：`Ctrl+K` 打开 `.qf-cmdk`（`role="dialog"`、`z-index === 90`）；输入 1 个字符后结果包含 4 类分组（页面/基金/股票/板块，空分组不渲染）；`ArrowDown`+`Enter` 完成跳转；**从冷启动到目标页面 active 的按键次数 ≤3**（Ctrl+K、1 个字符、Enter）；`Esc` 关闭且焦点回到原元素。

**US-5（面板三态 / S3）** 作为复盘用户，我希望每个面板都明确告诉我"在加载 / 真的没有 / 出错了"，这样我不会把"没数据"当成"没有机会"。
- 验收：当前页所有数据面板根节点带 `data-panel-state ∈ {loading, empty, error, ready}`；`empty` 态必须含 `data-empty-reason`（非空）且渲染 `.panel-empty-hint` 文案；`error` 态必须含 `[data-error-code]` 与 `.panel-retry` 按钮，点击后请求数 +1；`loading` 态显示骨架（`.qf-skel`）且面板高度与 `ready` 态差值 ≤8px（无 CLS）。

**US-6（表格 / S3）** 作为复盘用户，我希望表格数字对齐、表头吸顶、能按列排序，这样我能一眼找出最强的 3 个。
- 验收：`.qf-table` 单元格数字使用 `font-variant-numeric: tabular-nums` 且 `font-family` 命中 `--qf-font-mono`；`thead th` 在滚动 200px 后 `getBoundingClientRect().top` 与容器上沿差 ≤1px（粘性生效）；带 `data-sortable` 的列点击 3 次后 `aria-sort` 依次为 `descending → ascending → none` 且首行数值单调；单位出现在表头（`现价(元)`）而非单元格内。

**US-7（工作台模板 / S1）** 作为固定习惯用户，我希望把工作台布局存成模板，这样每次打开就是我关心的那几块。
- 验收：进入「编辑布局」后每个面板出现拖拽/上下移控件与「隐藏」开关；点击「保存为模板」后 `localStorage['qf.wb.layout.v1']` 存在且含 `{order:[], hidden:[]}`；刷新页面后 DOM 顺序与隐藏项与保存值一致；「重置」清除该键并恢复默认；内置预设 ≥2（盘中/复盘）。

**US-8（徽标与按钮 / S1）** 作为判读用户，我希望标题行最多 2 个徽标、每页只有一个主按钮，这样我知道该看什么、该点哪里。
- 验收：任一 `.page.active` 的头部行内彩色 chip 数 ≤2（其余进 `.qf-more-status` popover）；每页头部 `.btn-primary` 数 ===1 且位于头部右侧同一 x 坐标容器内；页面中部不存在游离的按钮组（`document.querySelectorAll('.page.active .btn-group')` 全部位于头部区域）。

**US-9（数据缺口 / S3）** 作为谨慎用户，我希望缺失的数字旁边能说明"为什么缺、什么时候恢复"。
- 验收：任何渲染为 `—` 的数值节点，其最近的可聚焦父节点或自身 `title`/`aria-label` 非空且包含「原因」或「更新」字样；页面顶部若有降级，仅出现 1 个 `.qf-degrade-chip`，点击展开含降级项列表与下一次刷新时间的 popover。

## 4. 需求池

> P0 = 必须做（本轮不达即不可上线）；P1 = 应该做；P2 = 可延后。
> 所有验收标准均给出可执行度量方式。

### P0-1 全局骨架：顶栏 48 + 上下文条 36 + 侧栏 56/168（含 flyout）

- **问题**：四层 chrome（56 topbar + 44 subtab + 60 标题 + 36 面板头）吃掉首屏 28%。
- **方案**：
  1. `.topbar` → 48px；logo 文字缩为 `QF` + 当前页名（≤10 字），省略「QuantFlow Pro 基金投资决策辅助」全称。
  2. 新增 `.qf-ctxbar`（36px，`position: sticky; top: 0; z-index: var(--qf-z-sticky)`）：左 = 一级页名 + 二级 tabs（行内文字 + 2px 青色下划线表示 active，tab 高 28px，命中区用 `::after` 撑到 32px），右 = 页面操作区（≤1 primary + ≤3 secondary + `⋯` 溢出菜单）。
  3. **删除** 页面内重复大标题与描述段（`.qf-page-title` 及 `.hud-group-header` 的标题容器），文案并入 ctxbar 左端。
  4. `.sidebar`：两态 56（仅图标，`title` + `aria-label` 兜底）/ 168（图标+中文标签+kbd），右上角折叠按钮，状态入 `localStorage['qf.sidebar.expanded']`；`hover`/`focus-within` 展开 `.qf-flyout`（220px，列出该一级页全部二级项，从 `STAGE5_PAGE_MAP` **只读**生成，禁止改写该对象）。
  5. 二级页切换仍走 `switchPage(name)`（签名与父子联动不改）；ctxbar tabs 与 flyout 都调用它。
  6. 内容区 padding 32 → 12（`--qf-space-*` 取 12px 需新增 `--qf-space-1-5:12px`，追加不覆盖）。
- **验收**：
  - `chromeHeight ≤ 136px`（1440×900，见 §6-M2），相对基线 ~252px 下降 ≥45%。
  - `.topbar` 高度 48px、`.qf-ctxbar` 高度 36px（`getComputedStyle`）。
  - 侧栏两态宽度实测 56/168，切换后刷新页面状态保持。
  - flyout 项数与 `Object.values(STAGE5_PAGE_MAP).filter(v=>v.parent===当前parent).length` 一致。
  - 全站 10 个存量页面（含旧 10 页映射）逐一点击，控制台 0 error、`STAGE5_PAGE_MAP` 零死链。
  - 移动端 390px：侧栏 `display:none`，汉堡按钮打开 overlay 抽屉（`z-index: 60`）。

### P0-2 顶部指数情绪条升级

- **问题**：`.index-item` 纯文字、无走势、不可点、与页面无关。
- **方案**：`.qf-index-bar` 条目结构 = `名称(12px muted) + 现价(13px, mono, 等宽) + 涨跌幅(11px, 红涨绿跌) + 迷你走势(48×16, 单折线用 `--qf-sem-up/down`, 不用渐变)`；条目顺序与条数由 `config` 决定，默认 4 条：上证指数、深证成指、创业板指、科创50；右侧追加 3 个「情绪极值」文本块：市场温度、情绪指数、涨停数（复用既有 derive 值，不新增计算）。点击条目 → 跳到行情上下文并选中该指数。数据缺失 → `—` + `title="<原因>（更新于 <时间>）"`。刷新周期沿用现有 60s。
- **验收**：条目 ≥4 且每条含走势节点；点击后对应卡片 `data-index-code` 命中并可见；缺失条目 `title` 长度 >0；在 1024/1280/1440 三档均不换行、不出现页面级横向滚动（`document.documentElement.scrollWidth <= innerWidth`）。

### P0-3 统一 Panel 三态 + 空/错态文案规范

- **问题**：空态/错误态混杂，文案各异，用户无法区分"没有"和"坏了"。
- **方案**：
  1. 定义 `.qf-panel` 组件：`header`（icon + title 13px + 可选 `subtitle` 11px muted + 右侧 actions ≤2 + `⋯`）+ `body`。头部高度固定 32px。
  2. **四态**（对 QA 暴露 `data-panel-state`）：`loading`（骨架 `.qf-skel`，与最终高度差 ≤8px）、`empty`（图标 + 15 字内原因 + 恢复提示 + 主操作）、`error`（错误码 + 重试）、`ready`。
  3. 空态文案模板（统一语法：**事实 + 原因 + 下一步**）：
     - 无数据：`今日暂无龙虎榜数据` / `原因：非交易日，下一交易日 17:30 更新` / 操作 `查看历史`
     - 未授权：`需要管理员 Token 才能读取持仓明细` / `原因：本地未配置` / 操作 `去设置`
     - 上游缺失：`上游未返回涨跌家数` / `原因：数据源降级，60 秒后重试` / 操作 `立即重试`
  4. 禁止裸 `—` 作为整块面板的唯一内容；禁止把错误文案写成空态样式。
- **验收**：`document.querySelectorAll('.page.active [data-panel-state]').length === 该页数据面板总数`（工程师在 PR 描述中给出该页面板清单）；4 种态各可用 URL/mock 复现（QA 用 `?mockPanel=empty|error` 或 DevTools 覆盖响应）；`empty` 必有 `data-empty-reason`、`error` 必有 `[data-error-code]` + `.panel-retry`；重试按钮点击后网络面板出现 1 次对应请求。

### P0-4 命令面板（Ctrl+K）

- **问题**：`Ctrl+K` 只聚焦一个输入框，页脚却承诺"搜索"；无键盘直达。
- **方案**：新建 `.qf-cmdk` 遮罩（`--qf-z-modal` 90，宽 640、最大高 60vh、背景 `--qf-bg-elev`、1px `--qf-line-2`、圆角 `--qf-radius-sm`），数据源 4 组：
  - **页面**：遍历导航结构（5 个一级 + 其子项，术语取自 DOM 标签，读 `STAGE5_PAGE_MAP` 不改它）
  - **基金/股票/板块**：优先用前端已加载的本地列表（自选、持仓、`sector_flow` 缓存），离线可搜；输入后可选异步补全（不得阻塞首字符结果）
  - 匹配规则：名称/代码/拼音首字母；最多 5 条/组
  - 交互：`↑↓` 移动、`Enter` 执行、`Esc` 关闭、`Tab` 切换分组；`/` 前缀只搜页面，`>` 前缀只搜标的（P2 可选）
- **验收**：3 次按键内到达任一页面（见 US-4）；空输入时显示「最近访问 3 条」；结果首屏 ≤50ms 出现（本地列表同步过滤）；`aria-activedescendant` 随移动更新；打开时 `document.body` 出现 `.cmdk-open` 且背景不可滚动。

### P0-5 表格规范 `.qf-table`

- **方案**：统一类：行高 32px（移动 40px）、`font-variant-numeric: tabular-nums`、数字用 `--qf-font-mono`、表头 `position: sticky; top: 0; z-index: var(--qf-z-sticky)` + `--qf-panel-bg-2` 背景 + 底部 1px `--qf-panel-line`；可选排序列加 `data-sortable` 与 `aria-sort`；单位进表头；空态在 `tbody` 内用 `colspan` 单行渲染（保留表头）；首列粘性（`left:0`）用于宽表（龙虎榜/板块龙头）。先在 4 张表落地：持仓表、基金表、板块龙头、龙虎榜。
- **验收**：见 US-6 全部条目；4 张表在 1280 宽下无横向溢出（`scrollWidth <= clientWidth`）或提供横向滚动容器（`overflow-x:auto` 且页面本身不滚）。

### P0-6 徽标收敛 + 页面操作区唯一化（原 P2-1/P2-2 提级）

- **问题**：头部 5 个彩色 chip；持仓页两组按钮分散两行。
- **方案**：头部最多 2 个 chip：第 1 个固定「交易时段」（中性色），第 2 个为最高优先级异常（critical > warn > info，只显示 1 个）；其余进 `⋯ 状态` popover（含数据就绪明细）。页面级按钮全部迁入 ctxbar 右侧：每页 1 个 primary，其余 secondary，超出 3 个进 `⋯`。
- **验收**：见 US-8；`⋯ 状态` popover 内条目数 = 被折叠 chip 数；持仓页所有按钮 `getBoundingClientRect().top` 差值 ≤4px（同一行）。

### P0-7 数据缺口必须解释（原 P1-4 提级）

- **方案**：新增统一 `qf-missing(value, reason, nextAt)` 渲染助手：输出 `—` + `<span class="qf-missing" title="原因…（更新于 HH:MM:SS）">`；页面级降级收敛为 1 个 `.qf-degrade-chip`（在 ctxbar 右端），点击展开明细（哪些字段降级、原因、下次刷新时间），替代原 4-5 个并行徽标。
- **验收**：见 US-9；抽查工作台「涨跌家数」「板块涨跌」两处，缺失时 `title` 非空；`.qf-degrade-chip` 每页 ≤1。

### P1-1 工作台模板（localStorage）

- **方案**：工作台右上进入「编辑布局」态：面板出现 ▲▼（顺序）与 👁（显隐），底部出现 `保存为模板 / 重置 / 预设`。存储键 `qf.wb.layout.v1 = {version:1, order:[panelId...], hidden:[panelId...], preset:"intraday"|"review"|"custom"}`；面板 id 由既有 `aria-label`/`id` 派生（不改渲染逻辑，仅在 `Workbench.load()` 之后按顺序 `appendChild` + 设置 `hidden`）。内置 2 个预设：`盘中`（承接/雷达/资金连增/持仓）、`复盘`（梯队/热度/纪律/统计）。
- **验收**：见 US-7；非法/旧版本 localStorage 值不得导致白屏（写入损坏 JSON 后刷新，工作台仍渲染默认布局且 key 被重置）。

### P1-2 面板密度档位（紧凑/舒适）

- **方案**：`html[data-density="compact|cozy"]`，compact = 行高 28 / 卡片 padding 8 / 面板间距 8；cozy = 现行值。入口在设置页，默认 compact，持久化 `qf.density`。
- **验收**：切换后首屏可见面板数 compact ≥ cozy；刷新保持；不影响任何图表容器尺寸计算（`ResizeObserver` 触发的图表无 0 宽）。

### P1-3 板块统计口径统一（原 P2-4）

- **问题**：`上涨 58（100%）` 与 `下跌 8（0%）` 同时出现 → 分母错误。
- **方案（产品口径）**：所有"占比"必须满足 **上涨数 + 平盘数 + 下跌数 = 参与统计板块总数 = 分母**，百分比按此分母四舍五入到 0.1%，三者之和 = 100.0%（允许末位 ±0.1 修正到最大项）。分母（参与统计总数）必须在 UI 上直接写出（如 `共 66 个板块`）。
- **验收**：板块页任意时刻 `up+flat+down === total` 且 `|upPct+flatPct+downPct - 100| <= 0.2`；`共 N 个板块` 文案存在；QA 用接口原始数据与 UI 数字逐项核对（允许 ±1 分钟时效差）。

### P2-1 面板更多操作 / 导出
- 面板 `⋯` 支持「复制数据（TSV）/ 在新页打开 / 隐藏该面板」。验收：复制内容可粘贴到 Excel 且列对齐。

### P2-2 自由拖拽栅格（明确延后）
- 真正自由拖拽（任意格位/跨列）不做；P1 只做上下移 + 显隐 + 预设。

### P2-3 策略页 K 线/五维面板尺寸修复
- 本轮只要求：布局改动后 1440/1280/390 三档下该面板容器宽度 ≥ 320px 且非零高度；根因（疑似渲染/尺寸）交架构师排查后再立需求。

## 7. 不做的事（明确排除）

1. **不引入前端框架/构建链**（Vue/React/Vite/Tailwind 一律不引入），继续原生 HTML/CSS/JS 直改 `web/static/`。
2. **不改后端 API 语义**：不新增/修改端点、参数、字段、错误码；不调整计算逻辑（温度、情绪、涨停数的算法保持现状）。
3. **不重写存量页面业务逻辑**：`switchPage`、各 `*.js` 的 `load/render` 契约不变；只允许"包一层 + 加属性 + 调 DOM 顺序"。
4. **不动 `STAGE5_PAGE_MAP`**：不增删键、不改 parent 映射；只读遍历。
5. **不做真正的拖拽自由布局**（P2 延后）；P1 只做上下移 + 显隐 + 模板/预设。
6. **不删除任何已有面板/数据字段**；隐藏必须可恢复。
7. **不改 `tokens.css` 既有 token 值**；新增 token 只追加。
8. **不动认证/Token 流程**，不改 `tokenBanner` 的判定条件（只改它的展示位置与样式）。
