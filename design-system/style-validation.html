RULES08

Do & Don't · 使用场景与禁用规则

未来科技感最容易失控的地方是"元素堆砌"。以下每组左为正确用法、右为禁止用法，规则来自规范文档 §8。

✓ 正确 · 霓虹只作用于描边与焦点

青色只做 1px 描边与外发光，底色保持深色。信号层面积占比 <5%。

✕ 禁止 · 霓虹大面积填充内容区
白字压渐变

白字在 #22E3FF 上仅 1.65:1，且大面积渐变让信号层失去焦点。

✓ 正确 · 玻璃层叠在实底 + 发丝描边
玻璃卡 · 1 层

不透明度 ≥55% + 1px 描边 + 顶部内高光，文字对比度实测 16.21:1。

✕ 禁止 · 玻璃叠在流动光斑上
文字后方有亮斑

亮斑扫过时文字瞬时对比度跌破 3:1，违反"特效不得影响可读性"。

✓ 正确 · 涨跌色 + 符号双重编码
▲ +2.14%▼ -1.32%

颜色 + 箭头 + 符号，色盲用户与强光环境均可辨认（WCAG 1.4.1）。

✕ 禁止 · 仅靠颜色区分状态
2.14%1.32%

缺少符号与方向标记，灰阶/色盲环境下两个数值语义完全相同。

✓ 正确 · 扫描线只在品牌区
AURORA TERMINAL

装饰元素仅用于品牌头图、转场、空态，不进入数据区。

✕ 禁止 · 扫描线进入数据表格
600519　1680.00　+1.24%

横向条纹干扰数值读取，违反"光只描边不填内容"。

十条硬性禁用组合

#禁用组合原因
01霓虹大面积渐变 + 玻璃层玻璃把渐变打散为噪点，文字对比度不可控
02流动光斑 + 正文文字（无遮罩）亮斑扫过时瞬时对比度跌破 3:1
03扫描线 + 数据表格 / 图表干扰数值读取
04霓虹色 + 涨跌 / 告警语义语义色必须唯一，混用造成误判
05同屏 ≥2 个大面积渐变视觉失去焦点，信号层超预算
06玻璃层嵌套 >2 层对比度不可预测，性能骤降
07glitch / shake + 可读正文或数值直接影响信息识别
08装饰动效 + 交互动效（同一元素）反馈被淹没，违反动效优先级
09展示字 + 中文正文 / 表格数字合成粗体导致糊字、失去等宽
10仅靠颜色 + 区分状态色盲与强光环境失效（WCAG 1.4.1）
